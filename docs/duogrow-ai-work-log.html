DuoGrow AI implementation handoff

A record of the product work completed for the user-facing AI experience, its privacy and cost controls, and the work intentionally left for a later release pass.

Requested product scope

The requested feature was a production-safe, user-facing DuoGrow AI capability. Four experiences were designed and implemented without adding a new primary navigation destination:

ExperiencePurposeWhere it appears
Daily CoachOffers a small, actionable nudge based on a safe summary of the user's recent activity.Today and verification-result surfaces.
Duo ReflectionOffers a mutual weekly reflection only after both people have opted in.Insights.
POTD TutorExplains a programming-problem concept and provides bounded tutoring help.Problem-of-the-day screen.
Ephemeral AI chatProvides a short support conversation that is deliberately not retained as a transcript.AI coach sheet.

Product and safety decisions

  • The feature is branded DuoGrow AI, not “Codex”; it does not execute code or expose an agent workspace.
  • AI is off by default. Personal consent is required before use, and Duo Reflection also requires current consent from both partners.
  • Users can revoke consent and delete associated AI preference metadata. Chat messages are not persisted.
  • The provider is server-side only. Browser code never receives the provider key.
  • Prompts exclude uploaded proof files, media, file paths, raw identifiers, invite tokens, and detailed proof-verifier output.
  • Production calls use the OpenAI Responses API with store: false, no tools, no background jobs, no file uploads, a bounded output, and a timeout.
  • When a live key is unavailable, the application uses deterministic demo behaviour so the product remains testable.
  • The default cost guardrails are three cents per user per day and twenty-five dollars per project per month, with separate request caps for each experience.

  • Added configuration defaults for model, per-user daily spend, project monthly spend, and feature request limits.
  • Added profile privacy controls and AI UI across Today, Insights, POTD, and verification-result flows.
  • Strengthened session handling, seeded-demo credentials, proof-media authorization, credential hashing, authentication attempt limiting, and cache controls.
  • Added request-size bounds to protect AI endpoints from oversized streamed JSON bodies.
  • Changed the UI to show the actual shared daily AI-cent balance rather than misleadingly summing individual feature limits.
  • Added operational documentation, a product design, an implementation plan, focused tests, and release handoff reports.
